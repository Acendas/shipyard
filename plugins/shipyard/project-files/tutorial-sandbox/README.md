# Tutorial sandbox

A small Node project with no dependencies, made for the Shipyard guided tutorial.

Three modules live in `src/`: `greet.js` builds a greeting, `total.js` adds up an order,
and `slug.js` turns a title into a URL slug. Two of them have tests in `test/`.

Run the tests with `npm test`.

The code is yours to change. Nothing here is used anywhere else.
